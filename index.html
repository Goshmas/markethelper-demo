GTIN в карточках

С 1 октября 2026 Wildberries проверяет карточки маркируемых товаров: к баркоду каждого размера нужно добавить GTIN из «Честного знака». Мы найдём коды, сопоставим их с размерами и запишем — после вашей проверки.

Шаг 1 из 5

Проверьте, каким карточкам нужен GTIN

  • Ключ API WildberriesКатегория «Контент». Для записи — с правом редактирования.

Проверка только читает карточки. Ничего не изменится, пока вы сами не подтвердите запись.

Как это работает

5 шагов, запись — только после вашей проверки
  1. 1

    Проверяем карточки Сейчас

    Находим размеры маркируемых товаров без GTIN. Только чтение.

  2. 2

    Подключаем «Честный знак»

    Вы входите по электронной подписи — доступ действует около 10 часов.

  3. 3

    Сопоставляем

    Сначала по артикулу, цвету и размеру, остальное — нейросеть по смыслу названий.

  4. 4

    Вы проверяете

    Каждая пара с меткой «Уверен», «Проверь» или «Не найдено» — в виде «было → станет».

  5. 5

    Записываем в WB

    GTIN добавляется вторым баркодом, старый остаётся. Только отмеченные вами пары.
